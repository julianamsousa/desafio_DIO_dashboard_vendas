# Xbox Game Pass – Dashboard de Vendas 🎮📊

## 📌 Objetivo
Transformar dados brutos de assinaturas em um **dashboard interativo no Excel**, permitindo análise clara do desempenho de vendas.

## 📂 Dados Utilizados
- Informações de assinaturas (ID, Nome, Plano, Data de Início, Auto-renovação, Preço, Tipo de Assinatura).
- Valores agregados de Season Pass (EA Play e Minecraft).
- Cálculos de faturamento total e segmentado.

## 📊 Dashboard
O dashboard apresenta:
- Faturamento total de planos anuais.
- Faturamento separado por auto-renovação.
- Vendas de EA Play Season Pass.
- Vendas de Minecraft Season Pass.
- Gráficos comparativos por plano e evolução temporal.
